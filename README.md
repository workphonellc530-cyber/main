## Quick Start

```bash
# Backend (AI Agents)
cd backend && pip install -r requirements.txt && uvicorn main:app --reload

# Frontend (Next.js)
cd frontend && npm install && npm run dev

# Or use Docker
docker-compose up -d
```

## Architecture

- **Frontend**: Next.js 14, Tailwind, conversion-optimized landing
- **Backend**: FastAPI, OpenAI/Anthropic integration, agent orchestration
- **AI Agents**: Lead gen, sales qualification, customer support
- **Marketplace**: Agent discovery, 25% commission, revenue share
- **API**: Enterprise-grade REST + WebSocket for real-time agents
